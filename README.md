## 🚀 Getting Started

### Prerequisites

- A modern web browser
- Git (for cloning)

### Installation

1. Clone the repository
```bash
git clone https://github.com/itexpert67/MY-PORTFOL.git
```

2. Navigate to the project directory
```bash
cd MY-PORTFOL
```

3. Open `index.html` in your browser
```bash
# On Mac
open index.html

# On Windows
start index.html

# On Linux
xdg-open index.html
```

Or simply double-click `index.html` to open in your default browser.
